A faster drop-in for make.fun's csv-reader 1.0.0. `solve.js` exports `run({text, header})` and returns exactly csv-reader's `{columns, rows, errors}` for every input, broken rows included: stray CRs, quote junk, unterminated quotes, short and long rows. It reads the text once over char codes, cuts fields with `slice` and allocates no per-field objects. A small warm-up at import runs every branch once, so V8 optimizes the parser before the first case. Nothing is kept from one case to the next.

Entry for the bounty [Read broken CSV files faster, 21 November 2026](https://make.fun/bounty/csv-reader-speed-01-run-20261121).

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```
